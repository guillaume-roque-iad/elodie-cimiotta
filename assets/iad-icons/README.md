# Iconographie iad

Source : charte iad 2025 fournie par Guillaume le 13 septembre 2026, pages 18 et 19.
Les tracés de ces SVG sont extraits des modèles vectoriels du PDF. Couleurs numériques : bleu #00B4EC et corail #EA584A. Préserver les proportions avec object-fit: contain.

Illustrations propriétaires (page 18) : check, home, growth, team, alert.
Pictogrammes (page 19) : mail, location, key, globe, document.

Réutiliser ces fichiers pour les articles FR/ES/CA. Éviter les emojis système décoratifs et les dessins génériques de substitution. Les étoiles des avis constituent une notation, pas une illustration. Ne modifier ni les notes ni le texte des témoignages.
